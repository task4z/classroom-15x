CS Cheat Sheet
Number Bases
Binary: base 2 (0, 1)
Octal: base 8 (0–7)
Decimal: base 10 (0–9)
Hex: base 16 (0–F)

Bit Operations
AND: 1&1=1, 1&0=0
OR: 1|0=1, 0|0=0
XOR: 1^1=0, 1^0=1
NOT: ~1=0, ~0=1

Byte sizes
1 byte = 8 bits
1 KB = 1024 bytes
1 MB = 1024 KB
